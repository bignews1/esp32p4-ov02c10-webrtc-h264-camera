# Public source snapshot — 2026-11-05

This update refreshes the previous camera reference files and adds camera color
controls and WebRTC microphone capture. Browser YuNet detection, multi-face
tracking and experimental SFace OWNER logic are included. Recognition accuracy
and tracking continuity depend on conditions and enabled options; this is not a
validated access-control implementation.

## Integration

This is an extracted source reference, not a standalone ESP-IDF project.
The parent integration uses ESP-IDF 5.5.4, ESP32-P4 Function EV Board, OV02C10,
ESP-hosted networking, ESP Peer, ESP Video, board audio APIs and modified H.264.
Project interfaces are not all bundled: settings.h, sound.h, lcd_ui.h,
flight_recorder.h, face_ai_detect.h, face_ai_tap.h, log_diag_policy.h,
sface_db.h, web_smoke.h, board helpers and ov02c10_webrtc_profile.h.
Supply compatible implementations and component build configuration.
Face database APIs need application authentication and access control.
The encoder parameter header moved from hw/include to hw/src to match its
implementation in the source tree.

## Public/private boundary

Included: camera, UI, protocol, detection/tracking/recognition algorithms,
audio capture and encoder source, with original third-party notices.
Excluded: private deployment configuration, actual TURN settings, Wi-Fi/MQTT/
admin credentials, personal photographs, enrolled embeddings, NVS dumps,
runtime logs, firmware binaries, archives, font files and personal backups.
Private development history is not merged into this public repository.
Browser and ESP TURN values use turn.example.com, YOUR_TURN_USER and
YOUR_TURN_PASSWORD. Configure your own service locally.
Public STUN, ONNX Runtime CDN and OpenCV model download URLs remain.
The embedded generic quantized YuNet detector is not an enrolled personal
face database. SFace weights are fetched from OpenCV Zoo at runtime.
See LICENSE_NOTE.txt and upstream model licenses.

## Validation

Source is normalized to LF; known deployment settings are replaced.
PUBLIC_SNAPSHOT_SHA256.json records the released source hashes.
Inline JavaScript and worker syntax are checked. The extracted public bundle
has not been built, flashed or tested on physical hardware for this update.
Earlier profile measurements are historical, not new snapshot benchmarks.
